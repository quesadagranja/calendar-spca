# Changelog

All notable changes to the public Calendar-SPCA research software are documented here.

## 1.0.0 — 2026

Initial public research release prepared alongside the Calendar-SPCA paper.

- unified the software identity under `calendar-spca`, `calendar_spca`, and `CalendarSPCA`;
- added the matrix-free cyclic calendar graph operators and joint sparse factorization estimator;
- added component matching, stability utilities, tests, and a self-contained synthetic example;
- documented the mathematical formulation and numerical conventions;
- added curated reproduction code for the factorial study, objective L-curve model selection, and final PCA/SPCA/SPCA-TV comparison;
- separated scientific configuration from machine-specific data paths and generated outputs.
